# ResQNet — CrisisLens-inspired homepage

This version uses a data-first crisis-intelligence structure inspired by the publicly described Crisis Lens project:
- live map first
- KPI/situation snapshot
- crisis intelligence brief
- workflow
- impact chain
- clear entry into the operational workspace

It is not a copy of Crisis Lens; the structure is adapted to ResQNet's disaster-response coordination concept.

All incident/resource values shown are demo data.
